# 🌱 Vegetable Container — Fullstack Demo

**Vegetable Container** là dự án demo Fullstack sử dụng **Next.js (SSG/ISR) cho frontend** và **NestJS cho backend**, mô phỏng quản lý dữ liệu nông sản.

- **Frontend:** Next.js, React, Tailwind CSS, componentized, SSG/ISR
- **Backend:** NestJS, REST API, server-side logic
- **Deployment:** Render (backend API), Vercel (frontend)

---

## 🔧 Tính năng

- Xem danh sách, chi tiết sản phẩm nông sản.
- Quản lý dữ liệu backend bằng NestJS REST API.
- Thiết kế responsive, tối ưu component reuse.
- Hỗ trợ SSG/ISR để cải thiện hiệu suất và SEO.

## 🛠 Kỹ thuật

### Frontend

- React, Next.js (SSG/ISR)
- Tailwind CSS, Shadcn/UI
- TanStack Query for data fetching
- Zustand (state management)
- Lottie animations

### Backend

- Node.js, NestJS
- REST API endpoints
- Typeorm / PostgreSQL (demo data)

### Tools & DevOps

- Git, GitHub, npm/yarn
- Vercel (frontend), Render (backend)
- ESLint, Prettier, TypeScript

---

## 🚀 Cách chạy dự án

### Backend (NestJS)

```bash
cd api
npm install
npm run dev
```

### Frontend (Next.js)

```bash
cd ui
npm install
npm run dev
```
